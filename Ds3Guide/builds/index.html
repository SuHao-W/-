BUILDS & EQUIPMENT

Optimized character builds, weapon recommendations, armor sets, and ring setups for every playstyle.

Top Meta Builds

Quality Build (STR/DEX) Meta

Core Weapon: Lothric Knight Sword, Hollowslayer Greatsword, or Black Knight Sword

Key Stats: VIG 27-40, STR 40, DEX 40, END 30-40

  • Armor: Any medium set. Lothric Knight Set or Alva Set for good defense/weight ratio.
  • Rings: Prisoner's Chain, Ring of Favor, Chloranthy Ring, Hornet Ring (for parries)
  • Infusion: Refined for most weapons. Sharp if DEX-focused, Heavy if STR-focused.
  • Strategy: Versatile, works with almost any weapon. The most reliable build for PvE and PvP.

Pyromancer Build Caster

Core Weapon: Onyx Blade or Dark-infused Longsword

Key Stats: VIG 27-40, INT 40, FTH 40, ATT 30

  • Spells: Chaos Bed Vestiges, Great Chaos Fire Orb, Black Flame, Carthus Flame Arc
  • Rings: Witch's Ring, Great Swamp Ring, Fire Clutch Ring, Sage Ring
  • Strategy: High burst damage. Chaos Bed Vestiges melts bosses. Keep distance and cast.

Sorcery Build Caster

Core Weapon: Court Sorcerer's Staff, Moonlight Greatsword

Key Stats: VIG 27-40, INT 60, ATT 30-40

  • Spells: Crystal Soul Spear, Great Heavy Soul Arrow, Homing Crystal Soulmass, Hidden Body
  • Rings: Young Dragon Ring, Bellowing Dragoncrest Ring, Magic Clutch Ring, Sage Ring
  • Strategy: Glass cannon. High damage but low defense. Use Hidden Body for stealth.

Faith / Lightning Build Caster/Melee

Core Weapon: Dragonslayer Swordspear, Lightning-infused Lothric Knight Greatsword

Key Stats: VIG 27-40, FTH 60, ATT 30

  • Spells: Lightning Spear, Sunlight Spear, Lightning Blade, Great Heal
  • Rings: Ring of the Sun's First Born, Lightning Clutch Ring, Sage Ring, Ring of Favor
  • Strategy: Buff weapon with Lightning Blade, then melee. Sunlight Spear for ranged burst.

Bleed / Hollow Build Status

Core Weapon: Warden Twinblades, Carthus Curved Sword, or Onikiri and Ubadachi

Key Stats: VIG 27-40, DEX 40, LCK 40-50

  • Infusion: Hollow (scales with Luck) or Blood (boosts bleed buildup)
  • Rings: Hollowslayer's Ring (if available), Pontiff's Right Eye, Chloranthy Ring, Ring of Favor
  • Strategy: Rapid attacks build bleed quickly. Carthus Rouge buff adds more bleed.
