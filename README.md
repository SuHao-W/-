## 📌 What is GamePanduan?

**GamePanduan** is a curated collection of comprehensive, player-focused game guides. We break down complex mechanics into clear, actionable strategies — covering everything from open-world RPGs to precision action games.

Whether you're stuck on a brutal boss, optimizing your endgame build, or hunting for hidden collectibles, we've got you covered.

## 🚀 How to Use

### Option 1: Browse Online
Visit the live site: **[gamepanduan.dpdns.org](https://gamepanduan.dpdns.org)**

### Option 2: Run Locally
1. Clone or download this repository
2. Open `index.html` in any modern browser
3. No server or build step required — pure static HTML/CSS/JS

### Option 3: Deploy Your Own
1. Fork this repo to your GitHub account
2. Go to **Settings → Pages**
3. Select **Deploy from a branch** → `main` → `/(root)`
4. Your site will be live at `https://yourusername.github.io/gamepanduan/`
