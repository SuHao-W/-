🎮 Getting Started

🆕 New Players

  • 🏰 Start with Barbarian or Rogue - easiest to learn
  • 📋 Complete the main campaign first before endgame
  • ⚡ Focus on ONE damage stat, not all stats
  • 🛡️ Cap your resistances at 70% before World Tier 3
  • 💰 Salvage magic/rare items for crafting materials

⚔️ Returning Players

  • 🔄 All classes have been rebalanced - check new builds
  • 📦 New Seasonal mechanics every 3 months
  • 🏆 Tier lists updated for current meta
  • 🎯 New endgame activity: The Pit for gem upgrades
  • 💎 Legendary aspects have been migrated to Codex
